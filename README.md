# ProfeCheck

Aplicacion web escolar construida con Next.js + TypeScript + Tailwind CSS + Supabase.

## Configuracion rapida

1. Copia `.env.example` a `.env.local`.
2. Coloca tus variables de Supabase.
3. Ejecuta el script de `supabase-schema.sql` en tu proyecto Supabase.
4. Instala dependencias y ejecuta:

```bash
npm run dev
```

## Rutas

- `/login`
- `/register`
- `/recover`
- `/dashboard`
